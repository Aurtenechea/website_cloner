# Proyecto de Descarga de Cursos

Este script automatiza la descarga de videos y materiales adjuntos de lecciones web.

## ⚠️ Requisitos
- **links.txt**: Una URL por línea.
- **cookies.txt**: Formato Netscape (7 columnas). **No subir a Git.**

## Configuración inicial
git init
git add .
git commit -m "Commit inicial"
git remote add origin https://github.com/Aurtenechea/website_cloner.git
git branch -M main
git push -u origin main
